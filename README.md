# Velomate — AI-Powered Cycling Training Dashboard

A self-hosted cycling training dashboard that connects to **Garmin Connect** and uses **Google Gemini** to generate personalised, adaptive weekly training plans based on your actual ride data.

## Features

- 📊 **Garmin Connect sync** — pulls your cycling activities automatically
- 🤖 **AI training plans** — weekly structured plans (Sprint, VO₂Max, Threshold, Tempo, Long Ride) generated by Gemini, adapted to your actual load and fatigue
- 💓 **HR zone analysis** — calculates your personal zones from LTHR/max HR with Garmin data as a starting point
- 📈 **Execution scoring** — AI reviews completed workouts and scores them 0–100 based on zone data, RPE and feeling
- 📅 **Week grid** — visual overview of planned, completed, skipped and auto-skipped days
- 🔄 **Garmin workout sync** — uploads structured workouts directly to your Garmin device
- 🌐 **Self-hosted** — all data stays on your machine; nothing is stored externally

## Prerequisites

| Requirement | Notes |
|---|---|
| **Garmin Connect account** | Regular login credentials (not SSO/social login) |
| **Google Gemini API key** | Free tier available at [aistudio.google.com](https://aistudio.google.com) |
| **Docker + Docker Compose** | For the recommended installation |

> **Note:** Velomate uses your Garmin username and password to connect via the Garmin Connect web API (the same flow your browser uses). Your credentials are stored locally in an encrypted session — they are never sent to any third party.

## Quick Start (Docker)

```bash
# 1. Clone the repository
git clone https://github.com/your-username/velomate.git
cd velomate

# 2. Build and start
docker compose up -d

# 3. Open the dashboard
open http://localhost:3001
```

That's it. On first run you'll be guided through the setup:

1. **Connect Garmin** — enter your Garmin Connect credentials
2. **Add Gemini API key** — paste your key from [aistudio.google.com](https://aistudio.google.com)
3. **Confirm HR profile** — review the suggested zones estimated from your ride history
4. **Generate your first plan** — one click and you're training

## Data Persistence

All data (activities, training plans, settings, HR profile) is stored in a SQLite database inside the `velomate-data` Docker volume. It survives container restarts and updates.

```bash
# View volume location
docker volume inspect velomate_velomate-data

# Backup your data
docker run --rm -v velomate_velomate-data:/data -v $(pwd):/backup alpine \
  tar czf /backup/velomate-backup.tar.gz /data
```

---

## Updating

```bash
git pull
docker compose up -d --build
```

Your data volume is untouched during updates.

## Configuration

All configuration is done through the in-app **Settings** panel — no config files or environment variables required.

| Setting | Where |
|---|---|
| Garmin credentials | Settings → Garmin section |
| Gemini API key | Settings → AI section |
| AI model | Settings → AI section (default: `gemini-2.0-flash`) |
| Preferred long ride days | Settings → AI section |
| HR profile (max HR / LTHR / zones) | HR Profile modal from dashboard |

## Custom Port

To run on a different port, edit `docker-compose.yml`:

```yaml
ports:
  - "8080:3001"   # access on localhost:8080
```

## Manual Installation (without Docker)

Requires **Node.js 20+** and **npm**.

```bash
# Install dependencies
npm run install-all

# Build frontend + backend
npm run build

# Start
npm run start
```

Open http://localhost:3001.

### Development mode (with hot reload)

```bash
npm run dev
```

- Frontend: http://localhost:5173 (Vite dev server with HMR)
- Backend: http://localhost:3001 (API only)
